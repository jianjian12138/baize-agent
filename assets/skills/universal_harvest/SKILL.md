# 🔱 技能：多态需求收割 (Universal Harvest)

本技能确立了 Matrix 引擎在面对混乱、零散的需求信息时的“格式归一化”能力。

## 🪐 1. 输入捕获模式 (Input Modes)
- **模式 A：音速收割 (Sonic)**
    - 针对 Axure/Figma URL。使用扫描器直接侦读内存对象。
- **模式 B：文本提纯 (Refining)**
    - 针对主公直接给出的 MD 文档、PDF 或聊天记录。执行语义降解，提取功能点、约束项与业务规则。
- **模式 C：视觉反向 (Vision-Reverse)**
    - 针对 UI 图片或录屏。识别元素布局、跳转逻辑与交互动效。
- **模式 D：仿写建模 (Cloning)**
    - 针对参考网址。克隆前端组件结构，但强制执行 Go/Postgres 逻辑重构，确证代码主权。

## 🛡️ 2. 处理规约 (Processing Rules)
- **拒绝模棱两可**：如果输入缺失关键路径（如：报错处理、空状态），必须立即调用 `Clarification` 技能与主公对齐。
- **结果降解**：所有输入必须统一解构为符合 OpenSpec 的 [**`需求文档.md`**](file:///d:/gogogo/assets/templates/) 格式。
