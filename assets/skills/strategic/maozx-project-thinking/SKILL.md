# 毛选项目思想技能集

将《毛选》核心理念（实事求是、矛盾分析、群众路线、实践检验）转化为可落地的项目管理工具。

## 技能导航

根据当前遇到的问题，选择合适的技能：

| 问题类型 | 对应技能 | 技能ID |
|----------|----------|--------|
| 项目启动、需求不明确、方案争议 | 调查研究 | maozx-investigation |
| 多任务并行混乱、优先级争议 | 抓主要矛盾 | maozx-main-contradiction |
| 团队协作低效、推广困难 | 群众路线 | maozx-mass-line |
| 过度讨论不敢行动、创新不确定 | 实践检验 | maozx-practice-first |
| 跨部门协作、利益冲突 | 统一战线 | maozx-united-front |
| 外部压力大、竞争激烈、资源不足 | 战略防御与进攻 | maozx-strategic-offensive |
| 项目复盘、事故分析、团队矛盾 | 批评与自我批评 | maozx-criticism |
| 项目周期长、团队疲劳、急于求成 | 持久战 | maozx-long-war |

## 使用方式

遇到项目障碍时，用以下自检问题找到对应的技能：

> **项目思维自检清单**
> 
> - [ ] 是否做过调查研究？
> - [ ] 是否识别了当前阶段的主要矛盾？
> - [ ] 方案是否经过群众路线验证？
> - [ ] 是否准备用实践检验代替无休止讨论？
> - [ ] 是否画过统一战线地图？
> - [ ] 当前应该防御还是进攻？
> - [ ] 最近一次批评与自我批评是什么时候？
> - [ ] 团队是否有持久战的心理准备？

## 核心理念对应

| 毛选原文 | 项目解读 | 适用场景 |
|---------|----------|----------|
| 没有调查就没有发言权 | 决策基于一手事实 | 项目启动、需求分析 |
| 抓住主要矛盾 | 集中资源打穿一个点 | 进度卡壳、优先级 |
| 群众路线 | 从群众中来，到群众中去 | 协作、推广 |
| 实践检验 | 从战争中学习战争 | 创新、不确定 |
| 统一战线 | 团结一切可以团结的力量 | 跨部门、政治 |
| 战略防御与进攻 | 知道何时退何时进 | 竞争、危机 |
| 批评与自我批评 | 复盘不去情绪化 | 复盘、事故 |
| 持久战 | 不是速胜论 | 长期项目 |

## 典型话术库

当需要用《毛选》语言表达时：

- "我们先不要急着出方案，分头去问三个最核心的用户/数据来源，明天汇总。"
- "如果我们只能做一件事让项目起死回生，那是什么？"
- "这个方案我们几个觉得挺好，但先让实际干活的人投个票，他们觉得不行就重来。"
- "争论一个星期不如明天上线一个小实验，错了我们就改，不丢人。"
- "我知道你们部门有自己的KPI，这个项目可以同时帮你们完成其中一项，我们坐下来对一下。"
- "现在不是硬拼的时候，我们先守住基本盘，三个月后等那个依赖接口上线，再一举反推。"
- "我先自我批评：上周的进度报告我晚了两天，导致大家后续排期紧张。这是我的责任。"
- "这个项目我们做好一年的准备，第一个季度只要把地基打稳，就是胜利。"
