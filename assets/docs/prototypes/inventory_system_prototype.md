## 🪐 1. 系统版图概览 (System Overview)

本系统旨在解决工厂刀模具（刀具、模具、量具）的数字化仓储管理。核心业务闭环如下：
- **基础准备**：物料、库位、供应商信息的全量维护。
- **实物受控**：通过“刀模具台账”实现单品（序列号级）物理掌控。
- **作业闭环**：现场领用、发放、归还、检验的全流程 PDA 作业。
- **决策支持**：实时库存报表与刀模具寿命统计分析。

## 🖥️ 2. PC 管理端详述 (PC Management Console)

### 📊 2.1 统计报表模块 (Reports)
- **库存报表页**
    - **主要指标**：物料编码、物料名称、物料类型、规格型号、计量单位、仓库、当前库存、待入库数量、待领用数量、可用库存、安全库存、状态（预警/正常）。
    - **交互**：支持按仓库、物料搜索；支持一键导出 Excel。
- **寿命统计报表页**
    - **核心字段**：刀模具唯一编码、已使用次数、设计寿命、剩余次数、使用比例（百分比）、状态颜色标识（正常绿色/临期橙色/超期红色）。

### 🧊 2.2 基础信息管理 (Configuration)
- **物料类型/信息**
    - **表单字段**：类型名称、父级类型、物料编码、物料名称、规格型号、默认存放仓库、预警阈值。
- **仓库与库位**
    - **层级架构**：仓库 -> 区域 -> 货位。
    - **属性**：库位编号、存放容量、当前装载量。
- **供应商管理**
    - **维护项**：供应商名称、联系人、联系电话、供应物料类别。

### ⛩️ 2.3 核心业务流 (Production Assets)
- **刀模具台账 (Tool Ledger)**
    - **单品属性**：唯一序列号 (SN)、物料编码、当前库位、当前状态（在库/已借出）、累计使用时长/次数。
- **领用发放管理**
    - **逻辑**：支持按申请单发放。核心字段包含申请人、申请部门、计划用途、预计归还时间。
- **归还入库管理**
    - **逻辑**：强制回填“本次使用次数”，系统自动更新台账中的寿命累计。
- **检验与报废**
    - **卡点**：归还后可触发“检验申请”，检验不合格则发起“报废流程”。

## 📱 3. 移动作业端 (Mobile/PDA Operations)

移动端专注于仓储现场高效作业，界面采用大图标、高对比度设计。

### 🔑 3.1 准入与导航
- **登录页**：账号密码准入。
- **首页金刚区**：**领用申领**、**领用发放**、**归还登记**。

### 🔍 3.2 现场查询
- **库存查询**：支持扫描物料条码/二维码直接展示库存余量、存放地（仓库-货位）。
- **库存详情**：展示物料的规格、单品 SN 状态。

### 📦 3.3 作业流程 (Workflow)
- **领用申领**：
    - 快速搜索 -> 勾选物料 -> 确认申请。
- **领用发放 (管理员模式)**：
    - 扫描员工卡 -> 扫描刀模具二维码 -> 确认出库。
- **归还登记**：
    - **扫描即核销**：扫描实物 SN 二维码 -> 逻辑自动带入物料信息 -> 输入使用次数 -> 确认入库。

### 📷 3.4 二维码/扫描逻辑
- **逻辑硬核**：全局搜索框支持调起摄像头扫码。
- **自动对齐**：扫描物料码自动填充“物料编码”，扫描库位码自动填充“目标库位”。

## 🛠️ 4. 业务逻辑建议 (Technical Insight)

基于原型深度扫描，白泽为您提供的工业化技术实现建议：
1. **数据模型**：建议建立 `material_ledger` (单品表) 与 `material_define` (规格定义表) 的 1:N 关联，确证寿命统计的精度。
2. **并发控制**：在移动端“领用”环节，需实现 Redis 级的分布式锁，防止同一 SN 被多人同时选中。
3. **离线能力**：建议移动端具备基础数据离线缓存，确证在仓库弱网环境下的扫码稳定性。
