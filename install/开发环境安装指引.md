# 开发环境安装指引 — Baize Agent V19.0.0

> 零第三方运行时依赖（纯 Python 标准库）。只需 Python 3.10+ 即可运行。

## 前置要求

- Python 3.10+（`python --version` 确认）
- Git（用于克隆/提交）
- Node.js / Go（可选，仅当你要开发 `projects/` 下的示例业务项目）

## 一键安装（对标 hermes-agent / pi-agent 体验）

Baize 提供跨平台一键安装，**任选一种**即可：

### Windows（原生）

```bat
install\install.bat
```

### Linux / macOS / Windows Git Bash

```bash
bash install/setup.sh
# 或等价地：
python install/bootstrap.py
```

安装器会依次完成：
1. 检查 Python 版本（≥ 3.10）
2. 复制 `.env.example` → `.env`（如已存在则跳过）
3. 运行环境门禁 `baize doctor`（必须 PASSED，否则会给出告警）
4. 完成安装（加 `--test` 可顺带跑测试：`python install/bootstrap.py --test`）

### 便捷目标（Makefile）

```bash
make install   # 等价于一键安装
make doctor    # 环境门禁
make test      # 跑测试
make index     # 构建技能索引
make clean     # 清缓存
```

## 手动安装（等价步骤）

```bash
# 1. 复制环境配置
cp .env.example .env

# 2. 按需修改 .env 中的 BAIZE_MODEL_* 与 SKILL_LIBRARY_PATHS

# 3. 环境门禁（必须 PASSED）
python -m baize doctor

# 4. 构建技能索引
python -m baize index build
```

## 配置模型端点（运行 Agent 必需）

编辑 `.env`，填入 OpenAI 兼容的模型服务：

```env
BAIZE_MODEL_BASE_URL=https://your-endpoint/v1
BAIZE_MODEL_API_KEY=sk-xxxx
BAIZE_MODEL_NAME=gpt-4o-mini
```

未配置时，`baize run` / `baize team` 会**拒绝启动并退出码 2**（fail-closed）。

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| `python` 命令不存在（Windows） | 使用 `py` 或 Python 完整路径 |
| doctor 报技能库 FAIL | 检查 `.env` 中 `SKILL_LIBRARY_PATHS` 路径是否存在 |
| pytest 未安装（仅测试需要） | `pip install pytest` |
| 想看可用命令 | `python -m baize --help` |
| `python -m baize` 报错 | 确保在仓库根目录执行，或确认 `baize/` 包完整 |

## 可用命令一览

| 命令 | 功能 |
|------|------|
| `python -m baize doctor` | 环境门禁检查 |
| `python -m baize index build` | 构建技能索引 |
| `python -m baize index search <关键词>` | 检索技能 |
| `python -m baize manifest validate <path>` | 校验项目 manifest |
| `python -m baize memory log/remember/recall/stats` | 跨会话持久记忆 |
| `python -m baize run "<目标>" [--resume <sid>]` | 运行单 Agent |
| `python -m baize team "<目标>"` | 运行 Director→Executor→Verifier 团队 |
| `python -m baize sessions [<sid>]` | 查看/续跑会话 |
