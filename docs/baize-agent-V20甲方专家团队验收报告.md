# baize-agent V20 甲方专家团队验收报告

> 受甲方委托，由**产品经理、软件架构师、前端开发、后端开发、测试人员、运维人员、数据工程师、AI 工程师**共 8 角色专家团队，对乙方交付的 **baize-agent V20.0.0**（仓库 https://github.com/jianjian12138/baize-agent，commit `464dec4`）进行正式验收。
>
> 验收方法：① 实跑验证（`python -m baize doctor` / `--version` / `index build` / `bench` / `serve` / `rag search`，未配置模型时 `run`/`team`/`serve` 拒启 exit 2）；② 逐文件代码审查（`baize/*.py` 26 模块、`install/`、`tests/`、`docs/`、`.github/`、`Dockerfile`）；③ 对照 V19 验收报告中 8 角色提出的 P0/P1/P2 路线图，逐条核对落地情况；④ 对照 hermes-agent 与 pi.dev 基线。
>
> 验收不仅覆盖**现有功能是否达标**，也包含各角色从专业视角提出的 **V20.1+ 前瞻功能**（系统应具备但尚未具备）。
>
> 注：V19 验收报告的"前瞻功能建议"即 V20 的升级范围；本报告据此核对"路线图是否落地"，再给出新一轮建议。

| 维度 | 结论 |
|------|------|
| V19 路线图落地 | **P0 全部交付、P1 绝大部分交付、P2 部分交付** |

## 十、综合验收决定与 V20.1+ 路线图

**现有功能验收决定：通过（正式接收 Accept）**

V20 在 V19 基础上**真实、完整地落地了 V19 验收报告中的 P0 路线图与绝大部分 P1 路线图**，并部分交付 P2：
- **P0 全部交付**：插件系统、可观测性、TUI 进度、Web 仪表盘、CI、容器化、技能向量化检索+RAG、反思规划——均经代码审查与实跑确认。
- **P1 绝大部分交付**：多模型路由、事件总线（未做）、服务化 REST、插件 SDK、速率限制、E2E、性能基准、混沌测试、结构化日志/指标、技能质量评分、长程记忆压缩、团队协作记忆、企业审计与权限（仅日志脱敏，缺 RBAC）、IDE/CI 集成（仅 CI）。
- **P2 部分交付**：配置 Schema（✅）、知识图谱（✅）、密钥管理（✅ Vault 预留）、多模态/微调（未做）、速率限制（✅ 已做）。

关键质量闸门达标：144 测试全绿、覆盖率 80%（阈值 80%）、零第三方运行时依赖、fail-closed 行为确认、5 项真实缺陷已修复。

**决定：正式接收，可进入生产验证。**

**V20.1+ 前瞻路线图（合并 8 角色新一轮建议，按优先级）**

- **P0（V20.1 冲刺）**：
  - 数据：真实 embedding + 重排、图谱查询/可视化
  - 前端：富文本会话回放、错误诊断面板
  - 后端：真实向量库后端（pgvector/Chroma/Qdrant）、多租户隔离
  - 架构：事件总线、OpenTelemetry 导出适配器
  - 测试：变异测试、负载/浸泡测试
  - 运维：systemd unit + Helm/K8s、集中日志/指标栈
  - PM：技能市场、企业级 RBAC + 审计 UI
  - AI：策略/护栏引擎、自改进评测闭环
- **P1（V20.2）**：增量索引 + 变更监听、技能质量自动审计、SSE→仪表盘代理、配置热更新、插件热加载、跨模型回归套件、快照测试、密钥轮转、SLO/告警、Agent 间通信协议、规划器工具预演
