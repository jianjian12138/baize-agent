## 三、基准测试执行与打分规约

### 1. 执行入口
```bash
# 运行白泽多 Agent 编排完成基准任务
python -m baize team "<BTS 任务描述>"

# 验证物理证据链与门禁
python -m baize manifest validate baize.manifest.json

# 审查执行轨迹与耗时分析
python -m baize sessions <session_id> --inspect
```

### 2. 评分维度（满分 50 分）
- **正确性 (0-10 分)**：是否完全达成任务目标，无逻辑缺陷。
- **完整性 (0-10 分)**：边缘条件、异常处理与类型声明是否完备。
- **工程质量 (0-10 分)**：代码简洁度、最小 diff、无冗余无污染。
- **可复现性 (0-10 分)**：是否具备独立测试与物理证据背书。
- **执行效率 (0-10 分)**：完成任务的 Token 消耗、Step 轮数与执行耗时。
