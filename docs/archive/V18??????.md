## 一、交付清单

### 1. 全新 baize 运行时（`baize/`，7 个模块，零第三方依赖）

| 模块 | 功能 | 对应评审问题 |
|------|------|--------------|
| `doctor.py` | 环境门禁：真实探测 Python 版本、目录、写权限、技能库路径、工具链，真实退出码 | 旧 environment_doctor 只 print 不拦截 |
| `skill_index.py` | 扫描 `SKILL_LIBRARY_PATHS` 全部技能库，构建 JSON 索引 + 关键词检索 | 旧 skill_bridge 硬编码 F:/ 断链 |
| `manifest.py` | 流水线门禁：phase=done 必须列证据且**文件物理存在**，否则 INVALID | manifest 门禁无代码校验、checksum 占位 |
| `memory.py` | 持久记忆：JSONL 日志 + notes.md + recall 检索 + stats 统计 | persistence/ 为空壳 |
| `cli.py` | 统一 CLI：`python -m baize doctor/index/manifest/memory` | 无可执行入口 |
| `config.py` | .env 解析（stdlib 实现），全部路径相对仓库根，可移植 | 硬编码盘符、变量错配 |

### 2. 真实测试套件（`tests/`，19 个用例，全部通过）

- 无 `assert True` 占位、无 MagicMock 屏蔽真实导入、全部真实文件/真实探测。
- 测试期间捕获并修复了一个真实 bug（索引器递归生成器缺 `yield from`）——证明测试链路在说真话。
- 核心规则「NO FAKE DONE」有专项测试：done 无证据 → 拒绝；证据文件不存在 → 拒绝。

### 3. 伪造代码清除

- 旧 `engine/`（41 个 py，1993 行，几乎全部含 Mock/Simulated）整体归档至 `legacy/engine-v17/`。
- 含明文口令的旧 `.env` 归档为 `legacy/env-v17.bak`，新 `.gitignore` 屏蔽 `.env` 与 `legacy/`。
- 伪造的模拟通过（hermes_coder `return True # Simulated`、matrix_loop `assert True`）不再存在于生效代码路径。

### 4. 技能整合（配置化引用）

- `.env` 的 `SKILL_LIBRARY_PATHS=D:/picasso-dev-skill/skills,D:/skills`。
- 索引实测：**278 个技能**（本地 assets/skills + 两个外部库），检索可用（如 `search tdd` 命中 4 项）。
- doctor 将技能库路径纳入必查项——路径失效即门禁失败，"文件搬家导致断链"问题从机制上杜绝。

### 5. 理念入技能

- 毛选战略 11 项技能（调查研究、主要矛盾、持久战等）保留于 `assets/skills/strategic/`，已纳入索引。
- 卡帕西外科手术式编码技能规范化 frontmatter，可被索引检索。
- AGENT.md 建立「场景 → 技能」调度表，理念成为可加载执行的规约而非口号。

### 6. 文档工程化

- README / AGENT / SKILL / START-HERE 四份顶层文档全部重写：中性工程文风、统一 **V18.0.0**（与 `baize.__version__` 一致）、每条规约标注强制执行者与测试文件。
- 删除全部无实现支撑的宣称（85% 覆盖率口号、156+ 插件、主权/恶意审计修辞）。

### 7. 示例项目 manifest 迁移

- `simple-shopping-platform/manifest.json` 迁移至新 schema，全部 evidence 修正为真实存在的文件路径（旧 manifest 中 `handlers/coupon.go` 等错误路径已修正为 `server/handlers/coupon.go`）。
- 实测 `validate` → VALID（此前旧格式被门禁正确拦截）。
