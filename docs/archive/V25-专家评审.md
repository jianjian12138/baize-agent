## 1. 评审框架

### 1.1 专家组组成

| 角色 | 评审重点 | 权重 |

- **NO FAKE DONE**:每条评分须有物理证据(命令输出/测试报告/git log/截图)

- **整改闭环**:未达 9.5 的项必须给出「文件:行号证据 + 自测回归」

## 4. 评分细则

### 4.1 打分公式

- 每项按 0 / 0.5 / 1 / 1.5 / ... 整数倍给分(根据每项满分)
- 总分 = 各专家分 × 25% 加权平均 → 折算 50 分制
- **红线 0 容忍**:任何红线破,总分直接判 0,必须整改复评
- **未达退出标准**:任一 E 项 ✗ → 整体拒收,不进入打分

### 4.2 通过门槛(强约束)

- 退出标准 E-01 ~ E-07 全部 ✓
- 4 人专家组加权平均折算 ≥ **45/50**(即 ≥ 9.5/10)
- 任何评分项 0 分,需有整改闭环(文件:行号 + 自测回归)

### 4.3 复评规则

- 首评未达 9.5,整改后 **7 天内**可申请一次复评
- 复评仍不达,推迟 V25 tag 至 V25.1
- 红线破禁止跳过整改直接复评
