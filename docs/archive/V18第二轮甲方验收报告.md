## 二、评审发现与修复记录

### 阻塞项（B 级 — 不修复则验收不通过）

#### B1. 商城零鉴权 — ✅ 已修复
- **问题**：`server/main.go` 所有写接口（POST/PUT/DELETE）无任何鉴权，匿名可调用
- **修复**：新增 `authMiddleware()`，写接口需 `Authorization: Bearer <API_KEY>`；API_KEY 从环境变量读取，未设置时 fail-closed（拒绝所有写请求）；GET 接口保持公开（商城前端可用）
- **证据**：`server/main.go:18-36` authMiddleware + `:62-81` 路由绑定

#### B2. 通配 CORS — ✅ 已修复
- **问题**：`r.Use(cors.Default())` 即 `AllowAllOrigins:true`，任意外部站点可跨域调用
- **修复**：改为 `cors.New(cors.Config{AllowOrigins: ...})` 白名单模式，从 `CORS_ALLOWED_ORIGINS` 环境变量读取，默认 `localhost:5173,5174`
- **证据**：`server/main.go:44-53`

### 建议整改项（M 级 — 影响交付质量）

#### M1. legacy/env-v17.bak 明文口令 — ✅ 已修复
- **问题**：`legacy/env-v17.bak:48` 含 `DB_PASSWORD=matrix_sovereign_pass` 明文口令
- **修复**：删除该文件
- **证据**：`ls legacy/` 不再含 env-v17.bak

#### M2. skill_index 计数虚高（278 含 29 重复）— ✅ 已修复
- **问题**：同名技能在 local + picasso-dev-skill + D:/skills 多处出现，索引不去重，"278 技能"夸大
- **修复**：`skill_index.py` build_index 新增按 name 去重逻辑（first occurrence wins，local 优先），新增 `duplicates_deduped` 字段
- **结果**：索引从 278 → **249 唯一技能**（去重 29 条）
- **测试**：新增 `test_build_index_deduplicates_same_name_across_libraries` 验证去重

#### M3. 生效文档死路径残留 — ✅ 已修复
- **问题**：`projects/skills/search-first.md:21-22` 写死 `E:\skills\`（不存在）；`projects/baize-domestic-service/` 三处写死 `F:/picasso-dev-skill`（不存在）
- **修复**：search-first.md 改为 `python -m baize index search`（并清理旧修辞"主权/魂智能力型技/白泽真理/Matrix V17.66"）；baize-domestic-service 三处 `F:/` → `D:/`
- **验证**：全仓 grep 确认生效路径无 `F:/picasso`、`E:\skills` 残留（仅 legacy/ 归档和历史评审报告中有引用）

#### M4. install 脚本与重构后结构错配 — ✅ 已修复
- **问题**：`install/sync.sh` 引用根目录不存在的 skills/profiles/shared/vendor/governance/workspace 目录；`doctor.sh`/`upgrade.sh` 同属旧架构
- **修复**：删除 doctor.sh / sync.sh / upgrade.sh 三个过时脚本；重写 `setup.sh` 为 V18 一键安装（复制 .env → doctor → pytest）；更新安装指引文档

#### M5. 同名技能三处漂移 — ✅ 已缓解
- **问题**：同名技能可能同时存在于 assets/skills/、projects/skills/、外部库，索引只指向其一
- **修复**：去重逻辑确保索引中同名技能只出现一次（local 优先）；AGENT.md 调度表已统一指向 assets/skills/ 路径

#### M6. search-first.md 旧修辞残留 — ✅ 已修复
- **问题**：仍含"主权原则""魂智能力型技""白泽真理""Matrix V17.66"等旧修辞，与文档工程化决策矛盾
- **修复**：重写为标准 frontmatter + 中性工程文风
