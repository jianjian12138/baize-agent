# 第 8 篇：看得见的工作 —— TUI / Web 仪表盘 / 协作记忆

> 适用读者：想知道"运行时怎么监控、怎么看进度"的小白。本篇讲清三种"看得见的"交互方式：命令行 TUI、Web 仪表盘、协作记忆查看。

---

## 8.1 为什么需要"看得见"

白盒引擎的核心主张之一是**过程可观测**。你不应该等 Agent 跑完才知道它干了啥——中途就能看到进度、卡哪了、用了什么工具。白泽提供三层可视化。

---

## 8.2 第一层：命令行 TUI 进度（run / team 自带）

当你跑 `run` 或 `team` 时，屏幕上实时打印的进度就是 TUI（Terminal UI，由 `baize/ui.py` 的 `ProgressUI` 渲染）。

它显示的内容包括：

| 进度元素 | 含义 |
|---------|------|
| `stage: plan` | 当前处于"规划"阶段 |
| `stage: act` | 正在调用工具行动 |
| `stage: observe` | 正在处理工具返回 |
| `stage: reflect` | 正在自我反思 |
| `tool: read_file` | 具体调了哪个工具 |
| 结尾的 `verdict / steps / tool_calls / session` | 本次运行汇总 |

两个开关：

```bash
python -m baize run "目标" --no-color   # 关闭彩色（适合日志文件/老终端）
python -m baize run "目标" --quiet      # 只显示结尾总结，不显示逐步过程
```

> 这些进度不是装饰，而是 `on_event` 回调从 Agent 内部真实事件流渲染出来的。

---

## 8.3 第二层：Web 仪表盘（serve）

除了命令行，白泽还能开一个**网页仪表盘**，在浏览器里实时看运行面板。

### 启动

```bash
python -m baize serve --port 8787
```

> 端口优先级：`--port` 命令行参数 > 配置文件 `BAIZE_SERVE_PORT`（默认 8787）。V20 修复过一个 bug：旧版里 `--port` 会被配置默认值覆盖而失效，现已修正为"命令行优先"。

### 打开页面

浏览器访问 `http://127.0.0.1:8787`（或你设置的 host/port）。

### 提供的 REST 端点

| 端点 | 方法 | 作用 |
|------|------|------|
| `/` 或 `/dashboard` | GET | Web 仪表盘页面（HTML） |
| `/health` | GET | 健康检查，返回 `{"status":"ok","version":"20.0.0"}` |
| `/metrics` | GET | **纯文本** Prometheus 指标（注意：必须是 text/plain，Prometheus 才能抓取） |
| `/sessions` | GET | 列出会话转录 |
| `/run` | POST | 提交一个目标，启动单 Agent |
| `/team` | POST | 提交一个目标，启动多 Agent 团队 |

示例：

```bash
# 健康检查
curl http://127.0.0.1:8787/health
# {"status":"ok","version":"20.0.0"}

# 启动一个任务（POST）
curl -X POST http://127.0.0.1:8787/run \
  -H "Content-Type: application/json" \
  -d '{"goal":"为 utils.py 写测试"}'
```

> 💡 注意 `/metrics` 返回的是**纯文本格式**（Prometheus 标准），不是 JSON。V20 修复过一个 bug：旧版返回了 JSON 字符串，会导致 Prometheus 抓取失败。

### 接入监控（Prometheus / Grafana）

因为 `/metrics` 是标准 Prometheus 格式，你可以：
1. 在 `prometheus.yml` 里加一个 job，scrape `127.0.0.1:8787`。
2. 在 Grafana 里建面板，看 Agent 运行次数、模型调用次数、错误数等指标。

指标端口也可单独配置：`BAIZE_METRICS_PORT`（默认 9090）。

---

## 8.4 第三层：协作记忆查看（team-memory）

这是"团队共享白板"的可视化（详见第 7 篇 7.6 节）。在多 Agent 协作时，你可以用命令实时看团队在白板上写了啥：

```bash
python -m baize team-memory show default    # 看共享笔记
python -m baize team-memory stats default    # 看统计
python -m baize team-memory clear default     # 清空（新任务前）
```

---

## 8.5 三种方式怎么选

| 你想要 | 用 |
|--------|-----|
| 跑任务时顺手看实时进度 | 命令行 TUI（`run`/`team` 自带） |
| 在浏览器里监控 / 团队共享看板 | Web 仪表盘（`serve`） |
| 接 Prometheus/Grafana 做长期监控 | `/metrics` 端点 |
| 看多 Agent 团队的共享上下文 | `team-memory show` |
| 事后回放某次运行 | `python -m baize sessions <session_id>` |

---

## 8.6 会话回放（sessions）

无论用哪种交互方式，每次运行都会留下 JSONL 会话日志。你可以事后查看：

```bash
python -m baize sessions                # 列出所有会话（含事件数、修改时间）
python -m baize sessions a1b2c3d4       # 看某次会话的完整转录（角色+内容+工具调用）
```

这是"可审计"的直接体现——任何一次运行都能完整回放。

---

## 8.7 本篇小结

- **TUI**：`run`/`team` 自带的终端进度，显示阶段/工具/反思，支持 `--no-color`/`--quiet`。
- **Web 仪表盘**：`python -m baize serve --port 8787`，提供 `/`、`/health`、`/metrics`、`/sessions`、`/run`、`/team`。
- **/metrics** 是 Prometheus 纯文本格式（V20 修复过 JSON bug），可接 Grafana。
- **协作记忆**：`team-memory show/stats/clear` 看团队共享白板。
- **会话回放**：`sessions` 命令完整回放任意一次运行。
