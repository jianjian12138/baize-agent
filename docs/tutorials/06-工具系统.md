# 第 6 篇：工具系统 —— 9 个内置工具与自定义工具

> 适用读者：想知道白泽"怎么动手干活"、或想给它加新能力的小白/开发者。本篇讲清 9 个内置工具和如何自定义工具。

---

## 6.1 工具是什么

Agent 的"思考"只是大脑，**工具**才是它的"手"。白泽给 Agent 提供一套**原语工具**（最基础、最通用的能力），Agent 通过调用这些工具来读写文件、跑命令、查资料。

所有工具通过 `ToolRegistry`（工具注册表）管理。注册表是**进程级单例**——这意味着：你自定义注册的工具，对之后创建的**每一个** Agent 都可见（这是 V20 修复过的真实缺陷，旧版本会把自定义工具注册进"一次性报废"的注册表，导致根本不生效）。

---

## 6.2 9 个内置工具清单

| 工具名 | 作用 | 典型参数 |
|--------|------|---------|
| `read_file` | 读取工作区内的文本文件 | `path` |
| `write_file` | 写入/覆盖工作区内的文本文件 | `path`, `content` |
| `list_dir` | 列出目录内容 | `path`（可选） |
| `bash` | 在沙箱内运行 shell 命令（deny-list 拦截） | `command` |
| `search_skills` | 按关键词搜技能索引 | `keyword` |
| `load_skill` | 按需加载某技能的完整 SKILL.md（渐进式披露） | `skill_file` |
| `memory_recall` | 检索持久记忆 | `keyword`, `tags`（可选） |
| `memory_log` | 把事件写入持久记忆 | `text`, `tags`（可选） |
| `save_skill` | 把新学到的可复用技能存下来（自进化） | `name`, `description`, `body_markdown` |

查看全部工具（及其 JSON Schema）的命令行方式：

```bash
python -m baize doctor    # 内部会校验工具注册情况
```

或者在代码里：

```python
from baize.tools import default_registry
print(default_registry().names())   # 打印所有工具名
```

## 6.3 重点工具详解

### bash —— 最受关注的工具

`bash` 让 Agent 能跑命令（比如跑测试、git 操作）。但它是**受限**的：

- **沙箱限制**：命令的工作目录被限制在 `BAIZE_WORKSPACE_DIR`（默认项目根）。
- **deny-list 拦截**：危险命令（如 `rm -rf /`、格式化、改系统配置等）会被**拒绝清单** fail-closed 拦截，直接不让执行。
- **超时**：默认 60 秒，防止卡死。

> 这就是为什么白泽"可控"：即便模型被诱导去执行危险操作，工具层也会挡住。

### save_skill —— 自进化能力

Agent 在完成任务过程中，如果"悟出"了一个好方法，可以调用 `save_skill` 把它存成技能文件。下次遇到类似任务，`search_skills` / `rag` 就能把它检索出来复用。这就是 hermes 的"自进化技能"思想。

---

## 6.4 安全机制小结

白泽的工具层有三道安全闸：

1. **沙箱**：工具只能访问 `BAIZE_WORKSPACE_DIR` 内。默认 `BAIZE_ALLOW_OUTSIDE_WORKSPACE=0`（禁止越界）。
2. **deny-list**：危险命令模式直接拒绝（fail-closed）。
3. **超时**：单条命令 60s 上限。

> 如果你想让工具能访问沙箱外路径，**必须**把 `BAIZE_ALLOW_OUTSIDE_WORKSPACE=1`——但文档强烈不建议，除非你完全清楚风险。

## 6.5 自定义工具：用 tool_sdk 扩展

白泽允许你**自己造工具**，给 Agent 加新能力（比如"发钉钉通知""查数据库"）。用的是 `baize.tool_sdk` 的装饰器。

### 示例：注册一个"问候"工具

```python
# my_tools.py
from baize.tool_sdk import tool

@tool(name="greet", description="向某人问好", args={"name": "string"})
def greet(name: str) -> str:
    return f"你好，{name}！"

# 必须在 Agent 启动前导入，注册才会生效
import my_tools  # 触发装饰器注册
```

关键点（V20 修复的真实坑）：
- **装饰器必须在 Agent 创建之前被导入执行**，注册才进"进程级单例"注册表。
- 注册表的调用约定是 `fn(**arguments)`——所以你的工具函数参数要能接收**关键字参数**展开。
- 工具函数返回字符串即可（会被包成观察结果反馈给 Agent）。

### 在自定义工具里调别的工具

如果你写的工具需要复用内置工具，通过注册表动态执行：

```python
from baize.tools import default_registry

def do_something():
    reg = default_registry()
    result = reg.execute("read_file", {"path": "README.md"})
    return result
```

## 6.6 一个完整的小例子

假设你希望 Agent 能"查询今天的天气"，而你的天气服务有个 HTTP 接口。你可以：

```python
# weather_tool.py
import urllib.request, json
from baize.tool_sdk import tool

@tool(name="get_weather", description="查询城市天气", args={"city": "string"})
def get_weather(city: str) -> str:
    url = f"https://api.example.com/weather?city={city}"
    try:
        with urllib.request.urlopen(url, timeout=10) as r:
            data = json.loads(r.read())
        return f"{city} 当前 {data['temp']}°C，{data['desc']}"
    except Exception as exc:
        return f"查询失败：{exc}"

import weather_tool  # 在启动 Agent 前导入
```

然后正常 `python -m baize run "查一下北京天气"`，Agent 就会自动用到你新加的 `get_weather` 工具。

> 注意：上面是示意。真实接入外部 API 请确认端点可用、密钥安全（放 `.env`，不要硬编码）。

## 6.7 工具调用的"契约"

Agent 调用工具时，传的是一个 JSON 参数对象，工具必须以**关键字参数**接收：

```python
# ✅ 正确：能接收 **arguments
def my_tool(arg1: str, arg2: int = 0) -> str: ...

# ❌ 错误（旧版 tool_sdk 的坑）：只收单个 dict
def my_tool(arguments: dict) -> str: ...   # 注册表用 fn(**arguments) 调用，会报错
```

## 6.8 本篇小结

- 白泽有 **9 个内置原语工具**：文件读写、列目录、bash、技能检索/加载、记忆检索/记录、技能自存。
- 工具层三道安全闸：**沙箱 + deny-list + 超时**，默认全部开启。
- `bash` 是受控的：危险命令被 deny-list fail-closed 拦截。
- 自定义工具用 `@tool` 装饰器，注册进**进程级单例**注册表（V20 已修复旧版失效缺陷），且参数约定为 `fn(**arguments)`。
- 注册必须在 Agent 启动前导入触发。
